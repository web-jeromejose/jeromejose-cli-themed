# Jerome Jose Portfolio

This is my personal portfolio site, built as a lightweight, fast, CV-led experience for sharing my work, background, and engineering focus.

## Development

You need Node.js and npm installed locally.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

## Available scripts

- `npm run dev` — run the app in development mode
- `npm run build` — production build for the TanStack Start app
- `npm run build:static` — create a static export for deployment
- `npm run preview` — preview the production build locally

## Stack

- TanStack Start
- React
- TypeScript
- Vite
- Tailwind CSS
